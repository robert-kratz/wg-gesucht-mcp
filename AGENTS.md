# Contributor instructions

- Never commit or push unless explicitly instructed by the user.
- Keep source, documentation, comments, and tool descriptions in English.
- Real WG-Gesucht accounts are production data. Never send messages, upload files,
  save profile/listing changes, or change advertisement status during development.
  Validate writes only against synthetic local fixtures.
- Never add credentials, authentication state, private HTML, messages, names,
  images, account identifiers, or production screenshots to tracked files.
- Run `pnpm check` before delivering changes. Keep Playwright and its container
  browser version in sync.
